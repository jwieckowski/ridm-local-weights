# Repository README

This repository contains the source code and datasets used in the research on the Risk-Informed Decision-Making (RIDM) method and its extension incorporating local criteria weights.

## Repository contents

- `analysis.ipynb` – Jupyter Notebook containing the code and data required to reproduce the calculations and analyses presented in the study..

## Reproducibility

To reproduce the results reported in the study, run `analysis.ipynb` sequentially. The notebook includes the computational procedures used to obtain the results presented in the manuscript.
